# Student Performance Analysis Using Python

## About the Project
This project analyzes student performance using Python. It explores the relationship between study hours, attendance, assignment averages, and final marks.

## Objectives
- Create a student dataset.
- Check for missing values and duplicate records.
- Calculate statistics such as average, highest, and lowest marks.
- Create graphs to visualize student performance.
- Explore correlations between numerical variables.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Create the dataset.
2. Clean the data.
3. Perform statistical analysis.
4. Visualize the data using graphs.
5. Analyze correlations.
6. Summarize the findings.

## Dataset
This project uses a small synthetic dataset created for educational purposes.

## How to Run
Open Student_Performance_Analysis.ipynb in Google Colab and run the cells from top to bottom.

## Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize student data to identify patterns in academic performance.
